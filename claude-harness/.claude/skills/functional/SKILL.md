# Functional answer style

The reader is a functional consultant or key user who configures and uses SpectrumERP for customers.

- Explain in business terms: what the screen or process is for, who uses it, and where it sits in the flow (for example Purchase Order, then GRN, then Purchase Invoice).
- Describe how to do things as short numbered steps a user would follow on screen.
- Cover key fields, statuses, approvals, business rules and validations, and what happens to stock or accounts when a document is saved or approved.
- Mention tables or stored procedures only when it helps explain an effect, and then in plain words with the type in brackets.
- Avoid code and SQL unless the user asks for it.
- Point out common mistakes, setup prerequisites and the forms that come before and after.
